Operating system · v4.3

TERMINA OS

A Unix-style system. On a microcontroller.

The system of Termina 80, written from scratch for the ESP32-S3. Processes, pipes, jobs and shell scripts; Lua 5.4 programs you write on the machine; Git, packages and a windowed desktop. All of it in 16 MB of flash.

Shell

It feels like Unix. Because it works like it.

Each command runs in its own process. Pipe them, redirect them, send them to the background, script them. Your muscle memory works here.

Processes and jobs

Pipes, redirections, background jobs.

|, >, 2>&1, &&, &. Ctrl+C interrupts, Ctrl+Z stops, fg and bg bring jobs back. Jobs keep running behind the desktop and the editor.

/$ find . -name "*.lua" | sort | tee list.txt | wc -l
27
/$ sleep 60 &
[1] 9
/$ kill %1
Signals

ps, kill, wait.

HUP, INT, KILL, TERM, STOP, CONT, PIPE and their friends, process groups and exit codes, as you know them.

Scripts

A small sh, for real.

if, for, while, case, functions, $(...), $((...)), ${X:-default}, read, test. A file name.sh runs as the command name.

# count.sh: count the lines of the files given
total=0
for f in "$@"; do
  n=$(wc -l < "$f")
  echo "$f: $n"
  total=$((total + n))
done
echo "total: $total"
The prompt

Comfortable at the keyboard.

History with ↑ and Ctrl+R search, Tab completion, wildcards, aliases, a /.profile and a bash-style PS1.

Shift+PgUp or the mouse wheel scroll back through the last 1000 rows. One clipboard is shared by the prompt, the editor and the desktop.

Programming

Write it here. Run it here.

Programs are Lua 5.4 files. Type edit game.lua, save, then type game. No PC, no toolchain, no flashing.

Lua 5.4

The standard language, and then some.

The full standard library: io, os, string, coroutine, require. The machine's own libraries live in the termina table, so the global table holds standard Lua only.

local term, key, sys = termina.term, termina.key, termina.sys
term.cls()
term.put(10, 5, "Press a key", 0x0A)
local e = key.wait()
print("You typed " .. (e.ch or e.key))
Isolation

A crash stays a crash.

Each program has its own Lua state and its own memory limit. When it runs out, it stops with "Out of memory", and the rest of the machine keeps running.

Compatibility

Upstream Lua code runs.

luasystem and LuaFileSystem are built in, with termios-style raw mode on the terminal. luasystem's own test suite runs on the machine with busted: 90 of its 95 tests pass.

PICO-8 carts

pico8 game.

Plays .p8 and .p8.png cartridges with its own implementation of the format and the API, scaled up on the HDMI screen.

Built in

Ready to work. Out of the box.

The tools a home computer needs, all running on the machine itself.

Git

A real Git client.

Clone, commit, push and pull over smart HTTPS to GitHub, GitLab or Gitea. The repository on the machine is a normal one: your PC's git reads it.

Packages

pkg install.

Community programs, modules, desktop apps and screen savers from the termina-packages registry, with their dependencies and SHA-1 checks. Add your own registries next to it.

Editor

Full-screen edit.

nano-style keys, selection, search and replace, undo and redo, syntax highlighting for Lua and shell scripts.

Web

A text-mode browser.

web searches DuckDuckGo and follows links with the keyboard or the mouse. telnet speaks ANSI.

Sharing

share on.

A web file manager on the machine: drop files on it from any browser on your network.

Storage

Unix paths, two disks.

An 11.9 MB flash filesystem, and a microSD card on /mnt/sd that cp, mv, Lua, git and pkg all see.

Play

Games, art and sound.

A snake game, a mouse drawing program, RTTTL melodies on the buzzer and screen savers you can write in Lua.

TERMINA WIN

Windows, the way they used to be.

Type win for a 3.1-style desktop driven by the mouse: icons, a taskbar with a Start menu and a clock, windows you move, resize, minimize and maximize.

Your apps

A desktop app is a Lua file.

Put -- @app Name at the top and it shows up on the desktop. Apps run at the same time, each with its own globals; an error only closes the faulty one.

-- @app Hello
local win = termina.win
local f = win.open{title = "Hello", w = 160, h = 60}
f:cls(15)
f:text(10, 20, "Hello!", 1, nil, "vga")
while win.event().type ~= "close" do end
Bundled

The essentials.

Files, Notepad, Clock, Settings and a real Terminal in a window, where commands, Git, pkg and your scripts run.

Drawn by the video card

Moving a window costs a few bytes.

The background, each window, the taskbar and the menus are kept as planes in the HDMI video card's memory. Moving or raising a window only changes their positions; only the rows whose contents changed go over the link. How the video card works ›

Under the hood

Small, and honest about it.

A microcontroller is not a PC. TERMINA OS gives you the Unix model on top of it, and tells you where it stops.

Your programsLua scripts, shell scripts, desktop apps, packages, screen savers.
Shell and toolsThe sh language, job control, Git, pkg, edit, web, TERMINA WIN, written in C++ and in Lua.
Lua runtimeLua 5.4 with 32-bit numbers. One state per program, memory taken from PSRAM, 1 MB each (2 MB for built-in programs and desktop apps).
KernelProcesses with PIDs, process groups, signals, file descriptors, pipes and an environment. Each process is a FreeRTOS task; they take turns whenever one waits, or every 20 ms for Lua. A terminal with termios-style modes and a scrollback.
DriversLittleFS and FAT on microSD, Wi-Fi with HTTPS and TLS, NTP time, the keyboard and mouse link from the PC, sound, LEDs and the OLED status screen.
HardwareESP32-S3 at 240 MHz, dual core, 8 MB PSRAM, 16 MB flash; a Raspberry Pi Pico 2W as HDMI video card.
